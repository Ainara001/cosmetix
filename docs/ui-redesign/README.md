# Единый стиль каталога и примерки: до / после

Сравнение сделано одним и тем же сценарием `integration_test/design_shots_test.dart` на iPhone 16 (симулятор), на демо-каталоге. Старые экраны: `before/`, новые: `after/`.

```bash
flutter test integration_test/design_shots_test.dart -d <SIMULATOR_ID> \
  --dart-define=SHOT_DIR=$PWD/docs/ui-redesign/after
```

Фото товаров на скриншотах взяты из проекта и **не имеют подтверждённых прав** (см. `docs/product-photo-rights-audit.md`): эти картинки нужны только для сравнения внутри команды и не годятся для публичной демонстрации. Для сборок, которые отдают другим людям, используйте `tools/rights/share_build.sh`.

## Что изменилось

| Экран | Было | Стало |
|---|---|---|
| Карточка палетки в списке | точки: по одной на вариант, цвет «с упаковки» | «Вариантов: 6 · цветов: 10», без цветовых точек |
| Страница палетки | круги с оценочным цветом каждого варианта, строка «Примерка недоступна: в каталоге нет данных» | варианты 00, 01, 02 ... как таблетки, десять нейтральных серых ячеек, одна пометка «Приблизительная передача оттенка», ссылка «О данных» (источник, дата, достоверность), выключенная кнопка «Примерить» |
| Страница помады | кнопка «Примерить» в стиле Material | кнопка `CustomButton` и одна пометка о приблизительности |
| Примерка | стандартные `SegmentedButton`, `ChoiceChip`, `FilledButton`, `OutlinedButton` | `PillSegments`, `AppChip`, `CustomButton` (обычная и компактная) |
| Примерка палетки | ячейки не выбирались | ячейка с известным цветом выбирается (сейчас таких нет: цвета ещё не измерены) |

Тёмная тема: все новые элементы берут цвета из `context.pal`, скриншоты `*-dark.png`.
