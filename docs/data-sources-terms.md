# Источники данных и опубликованные условия

Дата проверки: **2026-11-07**. Прочитано только то, что сайты сами отдают открыто, без обхода защиты, без переписки с магазинами. Это не юридическое заключение: вопросы, требующие профессиональной оценки, перечислены внизу.

Правило проекта: если разрешение на автоматическое получение данных не подтверждено, **парсер для источника не создаётся**. Отсутствие запрета в `robots.txt` разрешением не считается.

Статусы: **подтверждено**, **не подтверждено**, **использовать нельзя**.

**Ссылки на карточки товаров.** Ссылка на страницу товара не копирует содержимое, но ни у одного магазина я не нашла прочитанного положения о ссылках. В приложении ссылка показывается только если в реестре источников для этого магазина стоит «ссылки разрешены» и админ ввёл адрес вручную после просмотра страницы. По умолчанию для всех магазинов ссылки **выключены**. Cosmetix не называет себя партнёром магазинов.

## 3. Что требует профессиональной оценки

* Юридическая сила пунктов оферт магазинов о «воспроизведении содержимого» применительно к ценам как фактам (цена как факт не охраняется так же, как текст или фото, но вывод должен сделать юрист).
* Ссылки на магазины и возможные партнёрские ссылки.
* Использование состава с INCIDecoder.
* Согласие пользователя на обработку данных и порядок передачи на сервер.

Система **не** объявляется юридически проверенной.
